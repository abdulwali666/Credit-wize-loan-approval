CreditWise – Loan Approval Prediction

Project Overview

CreditWise is a Machine Learning project designed to predict whether a loan application should be approved or rejected based on applicant information.

The main goal of this project is to understand how machine learning algorithms can help with loan approval decisions.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

Machine Learning Models

I implemented and practiced the following supervised machine learning algorithms:

1. Logistic Regression
2. K-Nearest Neighbors (KNN)
3. Naive Bayes

Best Performing Model: Naive Bayes (based on my project evaluation).

Project Workflow

1. Data Collection
2. Data Cleaning and Preprocessing
3. Exploratory Data Analysis (EDA)
4. Data Visualization
5. Model Training
6. Model Evaluation
7. Model Comparison

Key Learning Outcomes

- Understanding supervised machine learning.
- Applying classification algorithms.
- Data preprocessing and cleaning.
- Comparing machine learning models.
- Using Python libraries for data analysis.
